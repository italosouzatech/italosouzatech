## Como penso sobre qualidade

- Investigar além do *happy path*.
- Priorizar falhas pelo risco e impacto para o usuário.
- Buscar causas-raiz, não apenas sintomas.
- Criar testes confiáveis, legíveis e sustentáveis.
- Prevenir regressões e reduzir o custo de correção.
- Tratar qualidade como responsabilidade compartilhada por todo o time.
